# Camfe
  • Built a campus-wide food ordering system for university students
  • Designed separate dashboards for customers and cafe owners
  • Implemented order tracking and menu management
  • Owners can list multiple cafes
  • Realtime delivery updates

## Features
- User authentication
- Add travel listings
- Upload images
- Reviews and ratings

## Tech Stack
- Node.js
- Express.js
- MongoDB
- EJS
- Cloudinary

## Installation
1. Clone the repo
git clone https://github.com/skydotcode/Camfe.git

2. Install dependencies
npm install

3. Run the server
npm run dev
